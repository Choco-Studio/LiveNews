The picture desk's face reader (tools/pictures/faces.mjs): a face detector (UltraFace RFB-320) finds the faces in a picture, an expression model (FER+) reads each one. window.__score(url) answers { w, h, faces: [{ x, y, w, h, score, emotions: { neutral, happiness, surprise, sadness, anger, disgust, fear, contempt } }] }. Models and the ONNX runtime are served from data/models (fetched once by the tool).
